# JV (Jview Visualization Suite)

The `JV/` (`code/JV/`) directory houses **`jview`**, the interactive OpenGL/X11/Motif 2D and 3D visualization environment for inspecting OMG bathymetric grids (`.r4`), sun-illuminated relief images (`.sun`), 8-bit greyscale rasters (`.8bit`), sidescan mosaics (`.mos`), and water column / swath geometry files.

## Core Tools

- **[`jview`](jview.html)** — Interactive 2D/3D raster, colour-draped bathymetry, and profile visualization tool.
