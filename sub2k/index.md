# Submetrix ISIS (`sub2k`) Interferometric Sonar Tools (`sub2k/`)

The `sub2k/` directory contains command-line converters, phase-unwrap simulators, and format decoders for **Submetrix Systems Ltd. (later SEA / Systems Engineering & Assessment Ltd.) ISIS 100 / 300 / Submetrix 2000 (`.sub`, `.rrc`, `.swa`)** wide-swath interferometric bathymetric sidescan sonars.

Unlike conventional beamformed multibeam echosounders that steer discrete receive beams and detect a single arrival time per beam, the Submetrix interferometric sonar measures **phase differences** across multiple vertically spaced stave elements (a multi-baseline Vernier interferometer) at every range sample along the port and starboard time series. The tools in `sub2k/` resolve phase-wrapping ambiguities, filter low-coherence returns, bin dense interferometric depth/range pairs into standard swath profiles, and export OMG `.merged` and `.ss_data` files.

> **Interactive GUI Counterpart:** For the interactive Motif/X11 real-time and post-processing graphical user interface built on top of `sub2k`, see the [`sub2k_motif/`](../sub2k_motif/index.html) directory (`RTsubx`).

| [`openISIS`](openISIS.html) | `sub2k/openISIS.c` | Utility library and standalone opener for validating and scanning Submetrix ISIS `.sub` file headers and packet framing | `.sub` | Header diagnostics |

## Typical Workflow

```bash
# Convert a Submetrix 2000 .rrc / .sub raw file into binned OMG .merged bathymetry and .ss_data sidescan
readSUB2K -in 000412_1030.rrc -out line01 -spacing 1.0 -thresh 40

# Convert a pre-processed Submetrix .swa swath file into OMG .merged format
readSWA -in line01.swa -out line01
```
