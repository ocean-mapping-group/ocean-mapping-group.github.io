# `wraps` — Pre-Generated Vernier Phase-Wrap Dataset (`asciiplot` Format)

## Overview

`wraps` (`sub2k/wraps`) is a 5,005-line ASCII plot data file generated by running [`testWrap -xplot`](testWrap.html) via the [`gox`](gox.html) script with stave spacings $d_1 = 3.0\lambda$, $d_2 = 6.0\lambda$, and $d_3 = 8.5\lambda$.

It is formatted for the Ocean Mapping Group's `asciiplot` utility and contains 5,000 `(dp12, dp23)` phase-difference coordinate pairs spanning $\sin(\theta) \in [-1.0, +1.0)$ in steps of $0.0004$.

---

## File Format & Structure

The first 5 lines of `sub2k/wraps` define the `asciiplot` axis bounds and series count, followed by 5,000 whitespace-separated `(dp12, dp23)` coordinate pairs in degrees:

```text
x: -180.0 180.0 90.0  dp12
y: -180.0 180.0 90.0  dp23
1
5000
0.00 0.00 
-0.43 -0.36 
-0.86 -0.72 
-1.30 -1.08 
-1.73 -1.44 
...
```

| Header Line | Content | Meaning |
| :--- | :--- | :--- |
| Line 1 | `x: -180.0 180.0 90.0  dp12` | X-axis minimum (`-180.0`), maximum (`180.0`), tick interval (`90.0`), and label (`dp12`, phase difference between staves 1 and 2 in degrees). |
| Line 2 | `y: -180.0 180.0 90.0  dp23` | Y-axis minimum (`-180.0`), maximum (`180.0`), tick interval (`90.0`), and label (`dp23`, phase difference between staves 2 and 3 in degrees). |
| Line 3 | `1` | Number of data series in the file (`1`). |
| Line 4 | `5000` | Number of `(x, y)` data points in series 1 (`5000`). |
| Lines 5–5004 | `<dp12> <dp23>` | Wrapped phase differences in degrees (`[-180.0, 180.0]`) for each increment of $\sin(\theta)$. |

---

## Usage with `asciiplot`

```bash
# Convert wraps into an OMG plot.meta file using discrete points
asciiplot -points -infile wraps

# View the resulting metafile
viewmeta plot.meta
```
