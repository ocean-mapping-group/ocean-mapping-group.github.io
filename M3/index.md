# Kongsberg Mesotech M3 Sonar (M3)

The `M3` directory contains converters and readers for **Kongsberg Mesotech M3** multi-mode imaging and profiling sonars (`.imb` and `.smb` formats), converting raw acoustic beam data into standard `OMG_HDCS` (`.merged`) and backscatter files.
