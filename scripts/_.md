# Additional Script Utilities (`code/scripts/`)

## Overview
In addition to the primary Kongsberg batch unravelers ([`unravel_KMALL_2500m_RevHplus_netatt2_parallel`](unravel_KMALL_parallel.html) and [`bunravel`](bunravel.html)) and mapsheet initializers ([`tor4`](tor4.html) and [`tomos`](tomos.html)), `code/scripts/` provides three general-purpose shell and Perl utilities for managing survey file prefixes, batch renaming, and script bootstrapping.

---

## Included Utilities

| Script | Language | Description |
|---|---|---|
| [`get_prefix`](get_prefix.html) | `tcsh` + `awk` | Strips the trailing `.ext` from input filenames (`awk -F. '{for (i=1;i<NF;i++) print $i}'`). Used internally by `tor4` and `tomos` to derive `<prefix>` from `<prefix>.blank`. |
| [`rename`](rename.html) | `perl` | Evaluates a Perl regular expression (`s/old/new/`) across a list of filenames (or `stdin`), supporting dry-run (`-n`), verbose (`-v`), and force-overwrite (`-f`) flags. |
| [`get_new_unravel`](get_new_unravel.html) | `tcsh` | Downloads and decompresses `new_unravel.gz` if `new_unravel` is not already present in the working directory. |

---

## Installation (`code/scripts/makefile`)
Running `make` in `code/scripts/` copies the executable scripts (`get_prefix`, `rename`, `get_new_unravel`, `tomos`, `tor4`) into the central OMG `$OMG_BIN` (`../../bin/`) directory so they are available on the user's `$PATH` alongside compiled C binaries.
