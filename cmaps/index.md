# Colormap Generation Utilities (`cmaps`)

The `cmaps` directory contains utilities for generating 256-entry RGB lookup tables (colortables) used by OMG visualization and image-rendering tools such as [`jview`](../JV/jview.html), [`scaleimage`](../vers/scaleimage.html), and [`array`](../subr/array.html).

---

## Tools in `cmaps/`

* [`CnCcolorMap`](CnCcolorMap.html) — Generates standard 256-entry (8-bit) RGB bathymetric and backscatter colormaps (`out256`) with configurable hue/saturation/value ramps.
* [`CnCcolorMapV`](CnCcolorMapV.html) — Variant colormap generator supporting customized value/brightness shading curves for sun-illuminated bathymetry overlays.

---

## Architectural Role
OMG raster files (`JHC_header`) store an embedded 768-byte (`256 x 3` unsigned char) RGB colormap (`rgb_cmap[768]`) or reference external colormap tables generated by `CnCcolorMap` and [`omg_colours`](../subr/omg_colours.html).
