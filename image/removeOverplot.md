# removeOverplot

## Description
`removeOverplot` is a prototype utility in `code/image/` (noted in `code/image/makefile` as `# STILL NOT FINISHED removeOverplot`) designed to work alongside [`shoalBias`](shoalBias.md) to suppress cartographic overplotting of adjacent shoal soundings using the exact sub-cell latitude/longitude offset grids (`<in>.lat` and `<in>.lon`).

## CLI Options & Usage
```bash
removeOverplot -in <shoal_grid.r4> -out <filtered_grid.r4>
```
* **`-in <shoal_grid.r4>`**: Input 32-bit float `OMG1` `.r4` bathymetry grid generated by [`shoalBias`](shoalBias.md), accompanied by `<shoal_grid.r4>.lat` and `<shoal_grid.r4>.lon`.
* **`-out <filtered_grid.r4>`**: Output 32-bit float `OMG1` `.r4` bathymetry grid.

## Algorithm
Opens `<in>`, `<in>.lat`, and `<in>.lon`, verifies that all three files are 32-bit float `OMG1` grids (`data_type == 3`), loads the depth array and sub-pixel coordinate offset arrays into memory, and writes the `OMG1` output grid `<out>`.
