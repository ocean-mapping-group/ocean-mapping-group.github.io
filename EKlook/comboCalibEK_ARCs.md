# comboCalibEK_ARCs

## Description
`comboCalibEK_ARCs` is a command-line utility for merging and calibrating broadband Angular Response Curves (ARCs) generated by [`BatchProcEK`](BatchProcEK.html) or [`EKlook`](EKlook.html):
1.  **Combining ARCs:** Merges multiple ARC files (3D or FFT bin-specific formats, such as lines collected at different transducer tilt angles) into a single composite ARC with optional bin-density stenciling (`-minfrac_MaxCount_toDump`).
2.  **Applying Frequency Calibration:** Applies a post-hoc frequency-dependent calibration curve (`-calib <file.txt.r4>`) and bulk offset adjustments (`-bulkcalibtoremove`, `-extradB`).
3.  **2D Slicing:** Extracts 2D frequency slices averaged over a frequency band (`-Freq2Dslice`) or grazing-angle slices averaged over a grazing-angle window (`-Graz2Dslice`).

## Usage

```bash
comboCalibEK_ARCs [OPTIONS] -out <output_prefix> -arcs <ARC_file(s)>
```

## Arguments

| Option | Description | Default / Example |
|---|---|---|
| `-v` | Enable verbose output. | |
| `-informat <format_id>` | Input ARC file format: `1` for 3D ARC (default), `2` for FFT bin-specific ARC. | `1` |
| `-outformat <format_id>` | Output ARC file format: `1` for 3D ARC (default), `2` for FFT bin-specific ARC. | `1` |
| `-bulkcalibtoremove <value>` | Bulk calibration offset (in dB) to subtract from the backscatter values. | `120.0` |
| `-extradB <value>` | Additional dB offset to add to the backscatter values. | `-10.0` |
| `-minValiddB <value>` | Minimum valid dB threshold for backscatter bins. | `-100.0` |
| `-minValidGrazing <degrees>` | Minimum valid grazing angle in degrees. | `10.0` |
| `-HzAverage <value>` | Frequency smoothing window (in Hz) when applying `-calib`. | `5000.0` (5 kHz) |
| `-minfrac_MaxCount_toDump <fraction>` | Minimum fraction of maximum bin count required for an ARC bin to be retained. | `0.0` |
| `-calib <Calibration_file.txt.r4>` | ASCII calibration file containing frequency and gain pairs for broadband spectral correction. | `calib_data.txt.r4` |
| `-Freq2Dslice <filename> <lowkHz> <highkHz>` | Output a 2D frequency slice to `<filename>`, averaging backscatter between `lowkHz` and `highkHz`. | `freq_slice.txt 50.0 60.0` |
| `-Graz2Dslice <filename> <lowGraz> <highGraz>` | Output a 2D grazing-angle slice to `<filename>`, averaging backscatter between `lowGraz` and `highGraz` degrees. | `graz_slice.txt 20.0 40.0` |
| `-out <output_prefix>` | **Required.** Prefix for the combined/calibrated output ARC files. | `combined_ARCs` |
| `-arcs <ARC_file(s)>` | **Required.** One or more input ARC files (`.ARC_fullBW`, `.ARC_3D`, `.ARC_FFTbins`, `.ARC_FFT3D`). | `survey_*.ARC_FFTbins` |

## Output Files
*   `<output_prefix>.ARC_fullBW`: Combined full-bandwidth ARC file.
*   `<output_prefix>.ARC_3D`: Combined 3D ARC file.
*   `debug.calib.sampled.txt`: Sampled calibration curve diagnostic output (when `-calib` is used).
*   `<outFslicename>` / `<outGslicename>`: 2D frequency or grazing-angle slice tables.
