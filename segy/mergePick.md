# mergePick

## Overview

`mergePick` linearly interpolates digitized seismic/sub-bottom reflector picks (from an interactive pick file) across all records of an ASCII multi-horizon seismic pick table (such as the `.picks` file generated by [`upsegy`](upsegy)) and writes the interpolated horizon into a selected trace column (`-p <0..8>`) in-place.

## Usage

```
mergePick [-v] [-s] [-p trace_index] [-c count] [-t threshold] infile outfile
```

## CLI Options

| Flag | Arguments | Default | Description |
| :--- | :--- | :--- | :--- |
| `<infile>` | `<path>` | *required* | First positional argument: input ASCII digitized pick file (containing image `width`, `length`, dummy integer, `nopicks`, and `nopicks` pairs of `record_index depth_sample`). |
| `<outfile>` | `<path>` | *required* | Second positional argument: target 12-column ASCII `.picks` file (`lat lon bottom trace[0..8]`) updated in-place (`r+`). |
| `-p` | `<0..8>` | `0` | Index of the horizon trace column (`trace[choice]`) to overwrite with the interpolated picks. |
| `-s` | none | `0` | Enable `showpick_flag`. |
| `-c` | `<count>` | `10` | Set record count parameter. |
| `-t` | `<threshold>` | none | Set floating-point threshold parameter. |
| `-v` | none | `0` | Enable verbose output. |

## How It Works

1. **Pick & Table Ingestion**: Reads image dimensions (`width`, `length`) and `nopicks` control points `(pick[1][i], pick[0][i])` from `infile`. Then reads all `num_rec` rows of `lat lon bottom trace[0..8]` from `outfile`, verifying that `num_rec == length`.
2. **Linear Interpolation**: For each ping `j` (`0 .. num_rec - 1`), locates the bracketing digitized picks `before` and `after`, computes the linear weight `(j - pick[1][before]) / (pick[1][after] - pick[1][before])`, and stores the interpolated sample depth in `new_bat[j]`.
3. **In-Place Update**: Rewinds `outfile`, assigns `trace[choice][j] = (int)new_bat[j]`, and rewrites all `num_rec` 12-column rows.

## Practical Examples

### Merge digitized reflector picks into horizon slot 1 of a `.picks` file

```bash
mergePick -v -p 1 reflector1.dig chirp_line01.picks
```
