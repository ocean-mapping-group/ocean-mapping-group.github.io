# rrmos.f (`mosaic`)

## Description
`rrmos.f` is a Fortran 77 3D sidescan translocation mosaicking program (`program mosaic`, written by John Hughes Clarke, Nov 1988 / Oct 1989). Unlike standard flat-seafloor slant-range correction ([`glslant`](../slant/glslant.html)), `rrmos.f` uses a ray-traced travel-time lookup table (`timearray(175, 750)`, generated by `RAY`) and a 512×512 bathymetric DTM (`bathy`) to project raw GLORIA time-series samples onto their true 3D topographic coordinates in latitude/longitude space.

## Interactive Inputs
1. **`enter travel-time array filename`** — Binary lookup table (`175` depth bins at `20 m` × `750` horizontal range bins at `20 m`, storing one-way travel times in milliseconds).
2. **`enter bathy filename`** — 512×512 floating-point bathymetric grid (`bathy(512,512)`).
3. **`enter output mosaic filename`** — Output 512×512 8-bit byte mosaic (`outarray`, `recl=512`).
4. **`enter sidescan filename`** — Raw 1024-byte GLORIA file (`head(1..6)` navigation/heading + `port(496)` + `stbd(496)`).
5. **`enter start and finish records for plotting`** — Scanline range (`istart`, `ifinish`).
6. **`enter max mosaic lat., min. mosaic long. and gridspacing (metres)`**.

## Algorithm
For each GLORIA ping, `rrmos.f` steps across-track in 15 m increments (`k = 1..1500`, `range = 15 m .. 22,500 m`) along the port and starboard beam azimuths:
1. Converts `(x, y)` to grid indices `(ix, iy)` and retrieves the true seafloor depth `depth = bathy(ix, iy)` at that location (handling acoustic shadows where `depth < maxdepth`).
2. Looks up the ray-traced travel time `time` in `timearray(idepth, irange)` for `(depth, range)`.
3. Converts `time` into the raw GLORIA sample index `igloria = int(time / 20.0)` and writes the acoustic intensity into `outarray(ix, iy)`.
