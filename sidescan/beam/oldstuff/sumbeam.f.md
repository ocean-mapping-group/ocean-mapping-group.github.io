# sumbeam.f (`sumbeam`)

## Description
`sumbeam.f` is a Fortran 77 program (written by John Hughes Clarke, December 1989) that reads multiple single-pass empirical GLORIA beam pattern files (`ps89_<pass>.beam_pattern` generated by [`glbeam_bypass`](glbeam_bypass.md) / `glbeam2`), accumulates the normalized corrections and mean Digital Numbers (DNs) across all specified passes for each of the 91 grazing-angle bins (`0°–90°`), and writes a pass-averaged `.beam_pattern` lookup table.

## Usage & Interactive Prompts
```bash
sumbeam
```
The program prompts interactively on `stdin` (`unit 5`):
1. **`enter number of beam patterns to sum`** — Integer count `n` of pass files to average.
2. **`enter pass numbers`** — `n` 3-character pass identifiers (`pass(k)`, e.g., `353`, `365`), expanding to `/u/jhc/data/sopac/gloria/ps89_<pass>.beam_pattern`.
3. **`enter output filename`** — Output path for the averaged 91-line `.beam_pattern` file.

## Algorithm & File Format
Each input `.beam_pattern` file contains 91 rows (`j = 1..91`, corresponding to grazing angles `0°..90°`) with five floating-point columns:
```text
xval(j)   stbd_val(j)   stbd_ave(j)   port_val(j)   port_ave(j)
```
where `*_val` is the multiplicative normalization factor and `*_ave` is the raw average DN (`0..255`). `sumbeam` sums `stbd_val`, `stbd_ave`, `port_val`, and `port_ave` across all `n` passes, divides by `float(n)`, and writes the resulting 91 rows in `(5(f8.2,2x))` format.
