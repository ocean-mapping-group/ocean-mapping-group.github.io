# JCU GLORIA Sidescan Processing Architecture (`code/sidescan/*`)

## Overview
The `code/sidescan/` directory tree implements the Ocean Mapping Group's sidescan sonar processing system, originally developed at James Cook University (JCU) by John Hughes Clarke and Guy Carpenter (1988–1991) for GLORIA MkII/MkIII long-range sidescan sonar surveys and later expanded at UNB to support Simrad EM-12/EM-1000 multibeam sidescan, SeaMARC I/II, Q-MIPS, USGS `xsonar`, and Triton `.xtf` datasets.

## The JCU GLORIA Record Format (`gloria_rec`)
Almost every tool in `code/sidescan/` reads and writes sequential fixed-length 1024-byte scanline records defined by `struct gloria_rec` in `jcu_glo.h`:
* **Header Block (first 32 bytes / 1024-byte aligned record)**:
  * Timestamp (`year`, `day`, `hour`, `min`, `sec` or decimal seconds / time mark flag).
  * Geographic position (`lat`, `lon` in decimal degrees or radians).
  * Towfish heading (`azimuth` in degrees/radians) and magnetic variation.
  * Nadir water depth / towfish altitude (`depth`, `alt` in meters) and slant-range correction status flag (`slant_flag`).
  * Port and starboard valid pixel counts (`GLORIA_SIDESIZE`, typically `496` or `512` 8-bit samples per side).
* **Acoustic Data Payload**:
  * `port_data[496]` (or `512` bytes) and `stbd_data[496]` (or `512` bytes) storing 8-bit unsigned Digital Numbers (`0–254`, with `255` or `0` reserved for invalid/no-data pixels).

## Standard Processing Pipeline

1. **Ingestion (`convert/`, `xtf/`)**:
   Convert vendor/agency raw files into `.ss` records using [`ios2glo`](convert/ios2glo.md), [`usgs2glo`](convert/usgs2glo.md), [`xsonar2glo`](convert/xsonar2glo.md), [`qmips2glo`](convert/Q-Mips/qmips2glo.md), or [`xtf2glo`](xtf/xtf2glo.md).
2. **Navigation & Attitude Conditioning (`azibat/`, `edit/`, `merge/`)**:
   Fix timestamp jumps ([`gltimefix`](edit/gltimefix.md), [`interpTime`](azibat/interpTime.md)), merge layback-corrected towfish azimuths ([`azimerge`](merge/azimerge.md), [`makeazi`](azibat/makeazi.md)), and low-pass filter yaw oscillations ([`smthazi`](azibat/smthazi.md)).
3. **Bottom Picking & Slant-Range Rectification (`slant/`, `seabed/`)**:
   Pick the first seafloor return ([`bpick`](slant/bpick.md)), smooth the nadir depth profile ([`smthbpick`](azibat/smthbpick.md), [`mergebat`](azibat/mergebat.md)), and project slant range to horizontal ground range ([`glslant`](slant/glslant.md) -> `.slr`).
4. **Empirical Beam Pattern & Gain Correction (`beammap/`, `gain/`)**:
   Map the 2D depth-vs-grazing-angle beam pattern across passes ([`mapbeam`](beammap/mapbeam.md), [`joinbeam`](beammap/joinbeam.md)) and remove across-track shading ([`debeam`](beammap/debeam.md) -> `.beam`, [`glgain`](gain/glgain.md)).
5. **Destriping, Gap Filling & Histogram Equalization (`destripe/`, `hist/`)**:
   Suppress ping-to-ping striping ([`destripe`](destripe/destripe.md), [`nadirdamp`](destripe/nadirdamp.md)), interpolate across-track/nadir gaps ([`glfill`](hist/glfill.md), [`glfudge`](hist/glfudge.md)), and equalize contrast ([`glhist`](hist/glhist.md)).
6. **Geographic Mosaicking (`mapmos/`, `print/`)**:
   Project scanlines onto a Mercator or geographic grid ([`mapmos`](mapmos/mapmos.md)) and export/print ([`printmos`](print/printmos.md), [`stretchacres`](../image/stretchacres.md)).
