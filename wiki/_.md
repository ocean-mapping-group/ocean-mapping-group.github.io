# OMG Code TiddlyWiki Archive (`code/wiki/omg_code.html`)

## Overview
`code/wiki/` preserves the historical single-file **TiddlyWiki** (`omg_code.html`, along with timestamped snapshots from November 2010 and January 2011 and `TiddlySaver.jar`) created by Jonathan Beaudoin, Steve Brucker, and James M. to document OMG command-line tools, compilation steps, and processing workflows between 2010 and 2013.

---

## Preserved Tiddler Articles in `omg_code.html`

### 1. System & Developer Guides
* **`How to obtain and compile the code`** — Instructions for checking out the OMG source tree and compiling `subr/`, `subr_graphics/`, and application directories.
* **`Adding new sounder tool types`** — Step-by-step instructions (by Jonathan Beaudoin) for registering a new multibeam or single-beam sonar in `OMG_HDCS_jversion.h` (`NO_TOOLS`, `tool_defs`, `packed_tool_defs`, `tool_names`) and configuring `Profile_BitsDefining` and `Beam_BitsDefining` bitmasks in `OMG_HDCS_jversion.c`.
* **`SVP Tool` & `WOD in svp_tool`** — Documentation for the sound velocity profile editor and World Ocean Database (WOD) climatology integration.
* **`Program Wiki Template`** — Standard template for documenting OMG CLI binaries.

### 2. Documented OMG Command-Line Programs
The TiddlyWiki contains dedicated usage articles (tiddlers) for the following core OMG utilities:
* **[`edhead`](../image/edhead.md)** — Inspecting and editing `JHC_header` metadata fields in OMG raster/grid files (`.blank`, `.r4`, `.mos`, `.8bit`).
* **[`fixnav`](../nav/fixnav.md), [`flagNav`](../nav/flagNav.md), [`stripNav`](../nav/stripNav.md), [`sumNav`](../nav/sumNav.md)** — Inspecting, speed-filtering, flagging, stripping, and summarizing binary `.nav` (`jcu_nav_rec`) ship navigation files.
* **[`useCMG`](../omg/useCMG.md) & `getHeading`** — Computing course-made-good (CMG) azimuth from GPS positions and extracting heading from `.merged` files.
* **[`getBounds`](../omg/getBounds.md) & [`inArea`](../omg/inArea.md)** — Generating `.global_bounds` and `.100_ping_bounds` spatial index files and testing whether survey lines intersect a target `JHC_header` mapsheet.
* **[`jview`](../JV/jview.md)** — Overview of the interactive X11/OpenGL DTM and swath viewer.
* **[`mos2`](../newmos/mos2.md)** — Sidescan and multibeam backscatter mosaicking workflow with `.mos` and `.ran` files.
* **`omg2hips`** — Converting OMG-HDCS `.merged` swath files into CARIS HIPS format.
